# Employee Attrition Analysis using SQL

## Project Overview

This project analyzes an HR Employee Attrition dataset using MySQL to identify workforce trends and factors contributing to employee turnover. The project demonstrates practical SQL skills through data exploration, data cleaning, business analysis, string functions, views, common table expressions (CTEs), and window functions.

---

## Objectives

- Explore the HR Employee Attrition dataset.
- Clean and validate the dataset before analysis.
- Identify departments and job roles with the highest attrition.
- Analyze the relationship between overtime, monthly income, and employee attrition.
- Demonstrate intermediate to advanced SQL techniques for data analysis.

---

## Dataset

The dataset contains employee information, including:

- Employee demographics
- Department
- Job Role
- Monthly Income
- Overtime
- Attrition Status
- Education
- Business Travel
- Years at Company
- Performance and other HR-related attributes

## Key Business Insights

- Sales recorded the highest number of employees leaving the company.
- Employees working overtime experienced a significantly higher attrition rate.
- Sales Representatives showed one of the highest attrition rates among job roles.
- Employees in the lower income category had the highest percentage of attrition.
- Research & Development employed the largest number of staff in the organization.
